# apellido-post1-u8

Laboratorio Unidad 8: Catálogo de Categorías y Productos con Spring Boot, Spring Data JPA, Hibernate y MySQL.

## Proyecto
`catalogo-jpa`: proyecto Maven Spring Boot (Java 17).

## Requisitos
- Java 17+
- MySQL 8.x con la base `catalogo_db` y el usuario `appuser`

## Ejecución
    cd catalogo-jpa
    ./mvnw spring-boot:run

Aplicación en http://localhost:8080/categorias
